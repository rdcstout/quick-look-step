# Contributing to QuickLookStep

For ordinary bug reports, include the macOS version, whether the behavior occurred in Finder preview, Finder thumbnails, or the app, and a minimal shareable STEP fixture when possible. For Finder registration issues, include the resolved file type from `mdls -name kMDItemContentType <file>`.

Keep changes focused and document how you verified the affected behavior. Before proposing a change, follow the [build and verification steps](DEVELOPMENT.md). For renderer changes, include examples that exercise the affected file variants. Avoid uploading proprietary drawings or paths containing personal data.
