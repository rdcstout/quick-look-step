# Foxtrot

The macOS viewer uses CDT, NURBS, STEP parsing, and triangulation
from [Formlabs Foxtrot](https://github.com/Formlabs/foxtrot) at
`69fb37688892246e670fc08eb60b7d3a92d70d3f`. The original
[MIT](LICENSE-MIT) and [Apache 2.0](LICENSE-APACHE) license texts
apply to that source. This checkout includes only the Rust libraries
linked into QuickLookStep and the sample STEP files used to validate them.
