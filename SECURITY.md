# Security reporting

Use [GitHub private vulnerability reporting](https://github.com/rdcstout/quick-look-step/security/advisories/new) for suspected vulnerabilities in Quick Look STEP. For ordinary bugs, use the [issue tracker](https://github.com/rdcstout/quick-look-step/issues).

Include the version or commit, macOS version, and the affected component. Describe the impact and attach a small shareable STEP file if it helps reproduce the problem. Keep proprietary models, private data, and vulnerability details out of public issues.

Security fixes target the latest stable release. Reports about unreleased code should include the affected commit.
